## M0 · 治理与规格

**目标**：把许可地位、流程、规格和选型全部定下来，然后才开始写代码。

**验收标准**

1. MIT 仓库建立，与 AGPL 前身仓库物理隔离，git 历史独立（无上游 remote、无 fork 关系）。
2. `CLEANROOM.md` 生效：8 条硬规则、规格审查标准、会话日志、逐文件来源表齐备。
3. `spec/engine-v1.md` 完成，通过 `CLEANROOM.md` §5 的自查。
4. `spec/ui-v1.md` 完成，含性能预算表。
5. ADR-0003（UI 框架）定稿并有实测依据。
6. 最小 CI 可跑：`cargo fmt --check` + `cargo check`（Linux + Windows）。

## M1 · 单源 HTTP 下载核心

**目标**：一个能真正把文件下下来、且中途断电不丢进度的引擎。

**验收标准**

1. 从本地 range server 下载 1 GB 文件成功，字节数与会话校验和一致。
2. 8 段并发下载达到本地链路上限；段数可配置，上限受控。
3. **断点续传**：下载到 50% 时 `kill -9`，重启后从断点继续，最终文件校验和与完整下载一致。
4. **动态分段**：下载中检测到某段落后时可拆分补段（行为规格定义）。
5. 全局限速与单任务限速误差 < 10%。
6. 失败分类正确：404 / 403 / 429 / 超时 / 连接重置 / 磁盘满 各有独立归因与可重试判定。
7. 任务、分段进度、配置全部持久化；宿主重启后状态一致。
8. 集成测试：`cargo test -p <engine>` 内含真实本地服务器的端到端用例。
9. 性能基线记录在 `PROGRESS.md`（吞吐、每段内存、CPU）。

## M2 · 多协议

**目标**：BT / 磁力、HLS/DASH、FTP/FTPS、SFTP 全部打通。

**验收标准**

1. 磁力链接：无 tracker（仅 DHT）也能拿到元数据并开始下载。
2. `.torrent` 文件：可选择文件子集下载。
3. HLS：能下载分片、按序拼装、处理 AES-128 加密流。
4. DASH：能解析 MPD 并下载选定清晰度。
5. FTP/FTPS 与 SFTP 各有一个真实服务器集成测试。
6. 统一的任务模型：四种协议的任务在持久化与事件出口上一致。
7. 元数据探测统一：大小 / 文件名 / 是否支持 range 的获取路径对四类协议都有定义。

## M3 · 多源聚合与镜像规则

**目标**：同一文件的多个镜像源分段并行，这是产品的核心增量。

**验收标准**

1. 镜像规则库：可从数据文件加载、支持按主机匹配与 URL 改写、支持优先级。
2. **一致性判据**：两个候选源被判定为同一文件时，证据必须包含总长度与强验证器；
   只有长度一致不得合并计数。
3. **凭据边界**：带凭据（签名 URL / Cookie / Authorization）的请求不得被发往非授权主机。
4. 加权分段分配：慢源让位、快源多担，且分配结果可解释。
5. 源健康度：只衰减不提升、未知不惩罚、有下限。
6. 端到端：两个本地源下同一文件，实际字节来自双方；**单源时行为与 M1 完全一致**（逐字节可比）。

## M4 · 中国大陆网络优化

**目标**：把"拉不动"和"说不清"这两个问题解决掉。

**验收标准**

1. 签名 URL 场景：URL 过期后的续签 / 重取路径有明确定义并经过测试。
2. 限流归因：区分"服务器拒绝"与"网络故障"，并触发对应的冷却策略。
3. 代理：HTTP/SOCKS5 代理、PAC 自动配置、系统代理发现（Windows）。
4. 失败诊断：每类失败有中文的"发生了什么 + 现在该做什么"，且词条有漂移守卫。
5. 真实站点冒烟：HuggingFace / npm registry / PyPI 各下一个真实文件成功。

## M5 · 桌面 UI

**目标**：一个真正好看、真正快的界面。

**验收标准**

1. `PLAN.md` §3 的性能预算表**全部达标**（冷启动 / 空闲 CPU / 空闲内存 / 5 万行滚动 / 刷新频率 /
   单帧 CPU / 内存 / 安装包体积）。
2. 中文界面无缺字、无排版错乱；中文输入法在搜索框内正常工作。
3. 主界面信息层级符合 `spec/ui-v1.md`：默认只显示任务列表与必要操作。
4. 托盘常驻、最小化到托盘、剪贴板监听、文件关联、单实例。
5. 高 DPI 缩放正常；窗口缩放时布局不破。
6. 浏览器嗅探扩展能把下载交给本机引擎。

## M6 · 打包发布

**目标**：干净机器上安装即用。

**验收标准**

1. Windows x64 安装包（体积 < 30 MB），卸载干净。
2. 代码签名；安装/更新过程无杀软误报。
3. 应用内更新：检查 / 下载 / 校验 / 安装全链路，可回滚。
4. 首次运行引导：默认下载目录、并发数、代理探测。
5. 发布流程可复现（一条命令或一次 CI 触发）。
